# Open&minimal

Open&minimal is a customizable, privacy-first Android launcher designed to make phone use more intentional. Choose a simple starting preset, then shape the home screen and app drawer to suit you—from an icon grid to a quiet text-only layout.

The public beta includes local notes and tasks, Android widgets, custom presets, and optional Focus Gate rules that add a pause or challenge before opening selected apps. Your launcher data stays on your device; the app has no Internet permission, account, ads, or analytics. The interface supports English and Turkish.

**[Download the beta APK](https://github.com/Burak-GGM/openminimal/releases/download/v0.3.0-beta.1/app-release.apk)** · Android 8.0 or newer. This is an early beta, so please [report issues](https://github.com/Burak-GGM/openminimal/issues).

For build instructions and implementation details, see [Development notes](docs/DEVELOPMENT.md). Read the [privacy policy](docs/PRIVACY.md) or its [Turkish translation](docs/PRIVACY.tr.md).
